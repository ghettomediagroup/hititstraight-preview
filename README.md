# Hit It Straight Golf Academy. Website preview

Private client preview built by **Ghetto Media Group LLC** for Hit It Straight Golf
Academy NFP (Homewood, IL).

**This is not the live site.** The live site is hititstraightgolfacademy.com and
nothing here has been published to it. This preview exists so the client can see and
approve the rewrite before any change is made to their GoDaddy account.

- `noindex, nofollow` on every page plus a blanket robots.txt, so this never competes
  with the client's real site in search.
- Layouts are deliberately plain. The real build has to be reproducible inside
  GoDaddy Websites + Marketing, which has fixed section templates and no custom code.
- Highlighted **NEEDED** text marks facts we do not have yet. Nothing is invented.
  No prices, dates, statistics or program names appear anywhere unless the client
  confirmed them.
- Photo slots are placeholders. Current site imagery is 2017 Facebook exports.

Source of the copy: audit and content pack, September 2026.
